## What this repo is

This is the course home for CAP2743C. Everything you need lives here:

- 📚 **Textbook** — chapter drafts as they're released

## Datasets

Two datasets in this course. See `datasets/README.md` for the full data dictionary.

| Dataset | Purpose | Where it's used |
|---|---|---|
| **AdventureWorks Sales** | Main course dataset — clean star schema, 7 tables, ~121K rows of bike sales | Labs 1–10, Capstone |
| **South Florida Beach Days** | Small EDA demo dataset for univariate/bivariate/multivariate analysis | Session 1 demo only |

Both files load directly into Power BI using the GitHub raw URL pattern. Full URLs in `datasets/README.md`. Conventions for how to use them in `CONVENTIONS.md`.
