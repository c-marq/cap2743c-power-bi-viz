# Sessions

One folder per class session. Each folder contains the student-facing materials for that class — guides, lab worksheets, slide handouts, and reference docs in self-contained HTML files.

## What goes in each session folder

A typical session folder contains:

| File | Purpose |
|---|---|
| `Session##_LaunchPad.html` | The class-arrival doc — agenda, what we're doing, what to have open |
| `Lab##_<Topic>.html` | The in-class lab worksheet with paste zones and reflection fields |
| `Reference_<Topic>.html` | Optional — quick-reference card for the day's tools or visuals |

All HTML files are self-contained: open them in any browser, fill in the textareas, paste screenshots (Ctrl+V into the paste zones), print to PDF, submit to Canvas.
