# Starter files

`.pbix` files that students download at the start of each lab. Each file is named for its lab and is a clean reference — do not edit in place.

## How to use a starter file

1. Download the file for the lab you're working on (e.g., `Lab02_VisualGallery_Starter.pbix`).
2. Open it in Power BI Desktop.
3. **Immediately do File → Save As** and rename it:
   ```
   LastName_FirstName_LabXX.pbix
   ```
4. Do all your work in the renamed file. Submit that file to Canvas.

This protects the starter for the next lab and makes your submission easy to grade.

## What's in each starter

Starter files arrive with the AdventureWorks data already connected and the model already built — that way you start where the lab focus begins. You won't need to rebuild the data model in every lab; the prereq course (CAP2791C) covered that, and this course focuses on visualization, analysis, and distribution.
