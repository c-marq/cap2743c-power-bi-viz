# Capstone

The capstone is the final integrative project for CAP2743C. It is revealed in Session 6 (May 28) and due in Session 12 (June 18). Students have approximately 3 weeks to build it, with protected work time in Session 11 and the tutoring hour after every class.

## What lives in this folder

| File | When it's released | Purpose |
|---|---|---|
| `Capstone_Brief.html` | Session 6 (May 28) | The project description — what's being built, why, what success looks like |
| `Capstone_Rubric.html` | Session 6 (May 28) | How it's graded — Excellent / Good / Needs Work tiers across components |
| `Capstone_Checklist.html` | Session 6 (May 28) | Tactical checklist students can run through before submitting |
| `Capstone_Starter.pbix` | Session 6 (May 28) | A clean AdventureWorks-connected `.pbix` to build the capstone from |
| `Capstone_Presentation_Template.pptx` | Session 11 (Jun 16) | Manus-friendly template for the optional live presentation |

## Capstone delivery options

Same as the prereq course pattern — students choose their submission format:

1. **Live presentation** (Session 12, opt-in, ~5 min per student)
2. **Recorded screen walkthrough** (~3–5 min video)
3. **Written reflection** (1–2 pages, addresses the same prompts as the recording)

No penalty for choosing not to present live. All three options earn the same possible score.

## Integration with the 8 chapters

The capstone is designed to integrate every chapter we covered:

| Chapter | What the capstone must demonstrate |
|---|---|
| Ch 1 | Clear visual hierarchy, chosen for the business question |
| Ch 2 | Multiple visual types — bar/column, line, scatter, map, KPI, table |
| Ch 3 | Branded theme + accessibility (alt text, tab order, contrast) |
| Ch 4 | Interactive — at least one slicer, one bookmark, one drill-through |
| Ch 5 | One analytics-pane feature (forecasting, reference line, or visual calculation) |
| Ch 6 | One AI visual (Decomposition Tree, Key Influencers, or Q&A) + one Copilot artifact |
| Ch 7 | Mobile-optimized layout + published to a Power BI workspace |
| Ch 8 | At least one Row-Level Security role configured and tested |
