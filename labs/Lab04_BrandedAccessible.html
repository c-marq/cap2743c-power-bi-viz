PHASE 2 — BUILD · about 20 minutes

Step 2 — Apply and customize a theme

💡 WHY ARE WE DOING THIS? A theme is one saved set of formatting decisions — colors, fonts, defaults — applied to every visual on every page at once. Instead of styling each chart by hand, you set the theme once and the whole report follows. This is the fastest single move from "plain" to "on-brand."
✅ DO THIS — apply a built-in theme first
  1. See it. The View tab of the ribbon has a Themes group with a gallery dropdown.
  2. Find it. Click the View tab → Themes group → open the Themes dropdown.
  3. Do it. Hover over a few presets to preview them live on your canvas. Click Executive. Every visual updates at once.
✅ DO THIS — now customize the theme
  1. View tab → Themes group → click the small drop arrow on the Themes button → Customize current theme.
  2. A dialog opens with tabs: Name and colors, Text, Visuals, Page, Filter pane.
  3. In Name and colors: set Theme name to AW-Lab4.
  4. Set the first data color to navy — type the hex value #1B2A47.
  5. Set the second data color to gold — type #C9A23A.
  6. Click the Text tab. Set the default font family to Segoe UI.
  7. Click Apply.
🛑 STOP AND CHECK Your bar chart should redraw — the bars now navy instead of teal, the text in Segoe UI. If a visual did not update: click it once to give it focus, then click an empty part of the canvas. Power BI sometimes waits for a re-render trigger. This is normal — not an error.

Step 3 — Add a matrix and apply conditional formatting (Rules)

✅ DO THIS — build the matrix
  1. Click an empty part of the canvas so no visual is selected.
  2. In the Visualizations pane, click the Matrix icon (a grid of small squares).
  3. From the Data pane, drag Product → Subcategory into the Rows well.
  4. From the Data pane, drag Sales Amount into the Values well.
  5. The matrix fills with product subcategories and their sales totals.
💡 WHY ARE WE DOING THIS? Conditional formatting changes how a value looks based on what it is. The Rules driver lets you set explicit threshold bands — under this number, between these numbers, above that number. Pre-attentive processing does the rest: a column of green numbers reads as "healthy" before the audience reads a single digit.
✅ DO THIS — apply the Rules driver Remember the shared pattern: select the visual → find the property → click fx → choose a style → configure → OK.
  1. Click the matrix to select it.
  2. Open the Format pane → find Cell elements.
  3. Find the Sales Amount field in Cell elements → switch the target to Font color → click the fx button next to it.
  4. In the dialog, set Format style to Rules.
  5. Click + New rule to add bands. Create these three:
    • If value >= 0 and < 1000000 → red
    • If value >= 1000000 and < 10000000 → orange
    • If value >= 10000000 → green
  6. Click OK.
⚠️ COMMON MISTAKE Students often apply the rule to the wrong field, or forget to switch the target from Background color to Font color. If your numbers did not change color, reopen the fx dialog and confirm: the target is Font color, the Based on field is Sales Amount, and you actually clicked + New rule for each band.

PHASE 3 — FORMAT · about 25 minutes

Step 4 — Build a small-multiples chart

💡 WHY ARE WE DOING THIS? A small multiples visual draws one chart once per category and tiles the results into a grid — same axes, same colors, one panel per category. The eye reads the whole system in a single sweep: which country is climbing, which is flat, which is collapsing — without a single click.
✅ DO THIS
  1. Click an empty part of the canvas so no visual is selected.
  2. In the Visualizations pane, click the Line chart icon.
  3. From the Data pane, drag Date onto the X-axis well.
  4. Drag Sales Amount onto the Y-axis well.
  5. Now find the Small multiples well in the Visualizations pane — you may need to scroll the pane down to see it.
  6. Drag Sales Territory → Country into the Small multiples well.
  7. The single line chart breaks into a grid — one mini line chart per country.
⚠️ COMMON MISTAKE If you do not see a Small multiples well at all, the current visual does not support it — small multiples work on line, area, bar, and column charts, but not on pies, donuts, cards, or maps. Confirm your visual is a Line chart before looking for the well.

Step 5 — Run the four accessibility checks

💡 WHY ARE WE DOING THIS? An accessible report is one a colleague using a screen reader, a board member with color vision deficiency, or a stakeholder squinting at a low-end projector can all actually use. There are four checks. You walk them at the end — like a pre-flight checklist — so you do not have to hold them in your head while building.
✅ DO THIS — Check 1: Alt text on every visual
  1. Click your bar chart to select it.
  2. Open the Format pane → General → find Alt text.
  3. Type a sentence that says what the chart shows, not what kind of chart it is. Example: Sales Amount by sales territory region, sorted descending.
  4. Repeat for the matrix and the small-multiples chart — every visual gets its own alt text.
✅ DO THIS — Check 2: Tab order follows the narrative
  1. Click View tab → Show panes group → Selection.
  2. The Selection pane opens on the right. Click Tab order at the top of the pane.
  3. Drag the visual entries into the order a keyboard user should meet them — typically the main chart first, then supporting visuals.
✅ DO THIS — Check 3: Color contrast meets WCAG AA
  1. Open a web browser. Search for a WCAG contrast checker and open one.
  2. Paste your foreground color (navy #1B2A47) and a white background (#FFFFFF).
  3. Read the ratio. WCAG AA requires at least 4.5:1 for body text. Navy on white clears this easily.
  4. Write the ratio you got in the response box below.
✅ DO THIS — Check 4: Screen-reader titles
  1. Click each visual in turn. Open the Format pane → General → Title.
  2. Confirm the title is descriptive — Sales by Region, not blank. A blank title makes a screen reader announce only "chart," which tells the listener nothing.
