PHASE 2 — BUILD · about 20 minutes

Step 2 — Build the drill-through detail page

💡 WHY ARE WE DOING THIS? Drill-through lets the audience right-click a data point and jump to a separate page built to show detail about exactly that point. You build the destination page first, then wire the trip to it. It is the opposite order from how it feels — but it is the order that works.
✅ DO THIS — build the detail page
  1. At the bottom of the screen, click the + next to the page tabs to add a new page. Double-click its name and rename it Customer Detail.
  2. On the new page, add a Bar chart: drag Customer to the axis and Sales Amount to values.
  3. Add a Card: drag Sales Amount into it.
  4. Add a Table: Customer and Sales Amount.
✅ DO THIS — wire the Drill through well
  1. Still on the Customer Detail page, click an empty part of the canvas so no visual is selected.
  2. In the Visualizations pane, find the field wells for the page itself. One is the Drill through well.
  3. From the Data pane, drag Sales Territory → Country into the Drill through well.
  4. Power BI automatically adds a Back button to the corner of the page.
⚠️ COMMON MISTAKE The Drill through well is a different well from the page filter section — they sit near each other. If your detail page later shows every country instead of just one, the field went into the wrong well. Confirm Country is in Drill through.
✅ DO THIS — take the trip
  1. Go back to the Sales Overview page.
  2. Right-click any country's bar in the column chart.
  3. In the menu, choose Drill through → Customer Detail.
  4. The Customer Detail page opens, every visual filtered to that one country.
🛑 STOP AND CHECK Arrive at Customer Detail by right-clicking one country — for example, United States. Every visual on the detail page should now show that country only, and you should see the Back button in the corner. Click Back to confirm it returns you to Sales Overview.

PHASE 3 — CONFIGURE · about 25 minutes

Step 3 — Create two bookmarks

💡 WHY ARE WE DOING THIS? A bookmark is a saved snapshot of the report's state — including which visuals are shown or hidden. With two bookmarks you can give one page two looks: a full Overview state and a focused state with the detail table hidden. The audience switches between them — one page, two views.
✅ DO THIS — open the panes you need
  1. Go to the Sales Overview page.
  2. Click View tab → Show panes group → Selection. The Selection pane opens — it lists every visual with an eye icon.
  3. Click View tab → Show panes group → Bookmarks. The Bookmarks pane opens.
✅ DO THIS — capture the first bookmark
  1. Make sure all three visuals are visible (all eye icons "open" in the Selection pane). This is the full Overview state.
  2. In the Bookmarks pane, click Add.
  3. Double-click the new bookmark's name and rename it Overview.
✅ DO THIS — capture the second bookmark
  1. In the Selection pane, click the eye icon next to the table visual to hide it. The table disappears from the canvas.
  2. In the Bookmarks pane, click Add again.
  3. Rename this new bookmark Focus.
⚠️ COMMON MISTAKE A bookmark captures the state at the moment you click Add — not before. If you click Add first and hide the table after, the bookmark will not hide the table. Always set the page the way you want it, then click Add. (If you got the order wrong, right-click the bookmark and choose Update.)
🛑 STOP AND CHECK In the Bookmarks pane, click Overview — all three visuals appear. Click Focus — the table disappears. If both bookmarks show the same thing, one was captured at the wrong moment; fix it with right-click → Update.

Step 4 — Add navigation buttons

💡 WHY ARE WE DOING THIS? Bookmarks are saved states, but the audience needs a way to trigger them. A navigation button is what they press. Two buttons — one per bookmark — turn your two saved states into a report the audience can actually drive.
✅ DO THIS — add the first button
  1. On the Sales Overview page, click Insert tab → Buttons → Blank. A button appears on the canvas.
  2. With the button selected, open the Format pane → find Action → turn it On.
  3. Set Type to Bookmark, and set Bookmark to Overview.
  4. In the Format pane, find the button's Text setting and type Overview so the button is labeled.
✅ DO THIS — add the second button
  1. Insert tab → Buttons → Blank again, to add a second button.
  2. Format pane → Action → On → Type Bookmark → Bookmark Focus.
  3. Set its Text to Focus.
  4. Position the two buttons side by side near the top of the page.
⚠️ COMMON MISTAKE In Power BI Desktop, a button does not fire on a normal click — that just selects the button for editing. To test it, hold Ctrl and click the button. (When the report is published, the audience just clicks normally.)
🛑 STOP AND CHECK Hold Ctrl and click your Focus button — the table should disappear. Ctrl-click Overview — the table comes back. Your report now switches between two views with buttons. That is a report app.
