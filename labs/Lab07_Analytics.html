PHASE 2 — EXPLAIN · about 18 minutes

Step 2 — Use the Analyze feature to explain a change

💡 WHY ARE WE DOING THIS? The Analyze feature answers why did it change. Right-click a data point and Power BI runs a machine-learning pass across the related tables and ranks the factors that moved the number. It does the first pass of an investigation that used to take days.
✅ DO THIS
  1. On the column chart of Sales Amount by Quarter, look for a quarter where the value dropped compared to the quarter before it.
  2. Right-click that quarter's column.
  3. In the menu, hover Analyze, then choose Explain the decrease.
  4. A pop-up opens with candidate explanations drawn as charts. Page through them with the arrows.
  5. When a chart looks like a real explanation, click the small + in its corner to add that chart to your report page.
⚠️ COMMON MISTAKE Treating the Analyze result as proven cause. Analyze reports statistical contribution — what the drop coincided with, not why it happened. It narrows the search; it does not close the case. In your written response you will be asked to explain this distinction, so notice it now.
🛑 STOP AND CHECK You should now have an extra chart on your page — the explanation chart you added with the +. If the Analyze pop-up said it could not find an explanation, pick a different quarter with a clearer drop and try again.

Step 3 — Add a Top N filter to the reseller chart

💡 WHY ARE WE DOING THIS? A reseller bar chart with every reseller on it is unreadable. A Top N filter keeps only the highest few — the top 10 — and re-ranks itself whenever a slicer changes. This is the fast, code-free route to a ranking that lives on one visual.
✅ DO THIS
  1. Click the bar chart of Sales Amount by Reseller to select it.
  2. Open the Filter pane on the right. Find the Reseller field in the Filters on this visual section and expand it.
  3. Change the Filter type dropdown to Top N.
  4. Set Show items to Top and type 10.
  5. Drag Sales Amount from the Data pane into the By value well.
  6. Click Apply filter.
🛑 STOP AND CHECK Your reseller bar chart should now show exactly 10 bars — the ten highest resellers by Sales Amount. If it still shows every reseller, confirm the Filter type is set to Top N and that you clicked Apply filter.

PHASE 3 — BUILD · about 28 minutes

Step 4 — Add a forecast to the line chart

💡 WHY ARE WE DOING THIS? A forecast answers what comes next. The Analytics pane projects a line chart forward — and draws a shaded confidence band around the projection. That band is the honest part: like a hurricane forecast cone, it widens the further out it reaches, because uncertainty grows with distance.
✅ DO THIS
  1. Click the line chart of Sales Amount by Date to select it.
  2. In the Visualizations pane, click the third tab — the Analytics pane (its icon is a magnifying glass over a line).
  3. Find the Forecast section and click Add.
  4. Set Forecast length to 3 months and Confidence interval to 95%.
  5. The chart extends with a projected line inside a shaded band. Leave the band visible — do not turn it off.
⚠️ COMMON MISTAKE Turning off the confidence band to make the forecast "look more confident." That is backwards — removing the band makes the report overstate how sure it is. A forecast is always presented with its band. Keep it.

Step 5 — Write a visual calculation

💡 WHY ARE WE DOING THIS? A visual calculation is DAX written directly on a visual — computed on the visual's own grid of rows, after the visual is drawn. Because it can see the rows in order, it can do row-aware math a measure finds awkward: a running total down the rows is a single line. This is one of the two skills new for the January 2026 PL-300 exam.
✅ DO THIS — add a table, then the calculation
  1. Click an empty part of the canvas, then add a Table visual from the Visualizations pane.
  2. Drag Date (set to the Quarter level) and Sales Amount into the table.
  3. With the table selected, go to the Home tab on the ribbon and click New visual calculation. An edit screen opens, showing the table's data as a grid with a formula bar above it.
  4. In the formula bar, type this exactly:
Running Total = RUNNINGSUM([Sales Amount])
  1. Confirm the formula, then close the edit screen. The table now carries a Running Total column that accumulates down the quarters.
⚠️ COMMON MISTAKE Expecting the visual calculation to show up in the Data pane so other visuals can use it. It will not. A visual calculation belongs to the one visual it was written on — no other visual can use it, no measure can reference it. If a result needs to travel, it has to be a measure instead.

Step 6 — Add a Smart Narrative

💡 WHY ARE WE DOING THIS? A chart shows a number; it does not say a sentence. Smart Narrative is a built-in visual that writes a plain-prose summary of the page — totals, trends, highs and lows — with values that update when the page is filtered. It drafts the summary; you, the analyst, review and own it.
✅ DO THIS
  1. Click an empty part of the canvas so no visual is selected.
  2. In the Visualizations pane, find and click the Smart narrative icon (it shows text lines or a speech bubble).
  3. Power BI generates a text box summarizing the current page.
  4. Read every sentence. Click into the text — it is editable. If any sentence is inaccurate or unclear, rewrite it in your own words.
⚠️ COMMON MISTAKE Trusting the generated text without reading it. Auto-written narratives can phrase a guess as confidently as a fact — especially the word because. The rule is simple: the narrative drafts, the analyst reviews and signs. Read every sentence before you accept it.
