Phase 2 of 4 — Find the Unusual 5 points

Phase goal: use two AI features that find something — clustering groups the data did not come labeled with, and an anomaly in a time series.

Task A — Cluster the resellers 2 pts

✅ DO THIS
  1. See it. In the Visualizations pane, the grid of icons includes a scatter chart (dots scattered in a square).
  2. Name it. Add a Scatter chart to the page. Put Sales Amount on the X Axis, Total Product Cost on the Y Axis, and Reseller in the Values well. Each dot is now one reseller.
  3. Find it. Hover the scatter chart → click More options (...) in its top-right corner → Automatically find clusters.
  4. Do it. Power BI proposes a number of clusters. Leave the number as proposed and click OK. It adds a Cluster field and recolors the dots by cluster.
⚠️ COMMON MISTAKE Treating a cluster as a real business segment the moment Power BI colors it in. Clustering finds dots that sit near each other mathematically. Whether those resellers share anything a business cares about is a separate question — and it is yours to answer. A cluster is a hypothesis, not a finding.

Task B — Flag an anomaly in time 3 pts

✅ DO THIS
  1. See it. Add a Line chart. Put Order Quantity on the Y axis and the Date table's Month on the X axis.
  2. Name it. With the line chart selected, the Visualizations pane shows three tabs — Build, Format, and Analytics. The Analytics tab has a section called Find anomalies.
  3. Find it. Visualizations pane → Analytics tab → Find anomalies → Add.
  4. Do it. Power BI shades an expected band along the line. If a point falls outside the band it gets a marker. Click any flagged point to open its explanation pane.
🛑 STOP AND CHECK A flagged point sits clearly outside the shaded band, with a marker on it. If nothing is flagged, that is a finding, not a failure — the series stayed inside its expected range; write that down as your answer. If Find anomalies is greyed out, your X axis is not a date — check that Month is on the X axis.

Phase 3 of 4 — Explain a Number 3 points

Phase goal: use the Decomposition Tree to break one number into its parts, and let the AI pick the most revealing split.

Task C — Build a Decomposition Tree 3 pts

✅ DO THIS
  1. See it. One Visualizations-pane icon is shaped like a small branching tree.
  2. Name it. That is the Decomposition tree visual. With no visual selected, click it to add one to the page.
  3. Find it. The visual has two wells — Analyze and Explain by.
  4. Do it. Drag Order Quantity into Analyze. Drag Group (SalesTerritory table), Subcategory (Product table), and Year (Date table) into Explain by. Click the + on the root node and choose High value — let Power BI pick the split that explains where the number is highest. Then click + once more and pick a field yourself.
💡 WHY ARE WE DOING THIS? The Decomposition Tree answers what is this number made of? — a different question from the Key Influencers visual, which answers what moves this number? Choosing High value hands the choice of split to the AI; picking a field yourself keeps you in control. You just did both, on purpose.

Written Response 1 — Run the five checks 2 pts

Pick one result from this lab — a cluster, the anomaly outcome, or a branch of your decomposition tree. Walk it through the five checks from Section 6.7: (1) Does it make business sense? (2) Is it correlation or cause? (3) Could the data behind it be biased? (4) Can you trace the numbers? (5) Would you sign your name to it? Write a sentence or two on each check.

Written Response 2 — What it did not tell you 2 pts

Your cluster scatter or your anomaly result found something. In your own words: what did that AI feature actually tell you, and what did it not tell you? Why does the difference matter before you would show the result to a manager?
